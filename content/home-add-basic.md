# iPhone・Androidで「ホーム画面に追加」する方法をわかりやすく解説

毎日開くWebサイトを、そのたびに検索したりブックマークから探したりするのは面倒です。そんなページは、スマホのホーム画面にアイコンとして置いておくと便利です。

この記事では、**iPhoneのSafariとAndroidのChromeでWebページをホーム画面に追加する方法**を、操作の順番に説明します。追加したアイコンの名前や画像が思いどおりにならない理由も整理します。

## 「ホーム画面に追加」とは？

Webページを開くためのアイコンを、スマホのホーム画面に置く機能です。App StoreやGoogle Playで専用アプリを探す必要はありません。

ただし、追加したものが必ず「アプリ」になるわけではありません。普通のWebサイトならブラウザで開くショートカットになることがあり、Webアプリとして構成されたサイトなら、アドレスバーのない独立した画面で開くこともあります。**見た目や起動方法は、OS・ブラウザ・サイト側の設定によって変わります。**

## iPhone：Safariでホーム画面に追加する方法

1. **Safari**で追加したいWebページを開きます。
2. Safariの**共有ボタン**（四角から上向き矢印が出ているマーク）をタップします。ボタンの位置はSafariのレイアウトによって異なります。
3. 共有メニューをスクロールして、**ホーム画面に追加**を選びます。
4. 表示名を確認し、必要なら編集します。「Webアプリとして開く」などの選択肢が表示された場合は、希望する起動方法を選びます。
5. **「追加」** をタップします。

ホーム画面に戻ると、追加したアイコンが表示されます。

### LINEやInstagramから開いた場合は？

LINE、Instagram、Xなどでリンクを開くと、アプリ内ブラウザで表示されることがあります。その画面ではSafariと同じ追加メニューが使えない場合があります。

アプリのメニューから「Safariで開く」を選ぶか、URLをコピーしてSafariで開き直してください。

## Android：Chromeでホーム画面に追加する方法

1. **Chrome**で追加したいWebページを開きます。
2. 画面の **︙（メニュー）** をタップします。
3. **ホーム画面に追加** または **アプリをインストール** などの項目を選びます。
4. 表示される案内に従って、名前や追加先を確認し、 **「追加」または「インストール」** を実行します。

Androidでは、サイトがインストール可能なWebアプリとして認識されているかどうかなどによって、表示される文言や追加後の動作が変わります。メニューに「インストール」と書かれているからといって、すべてのWebサイトで同じ画面・同じ機能になるわけではありません。

## アイコンや名前は自由に変更できる？

**名前は追加時に編集できる場合がありますが、アイコン画像は通常、サイト側が用意したものを使います。**

iPhoneではHTMLの`apple-touch-icon`など、AndroidではWeb App Manifestの`icons`などがアイコン選択に関係します。サイトによっては個別の商品ページを追加しても、サービス全体のロゴが表示されます。

たとえばお気に入りのショップの特定の商品ページを追加しても、ショップ共通のアイコンになることがあります。これは故障ではありません。

なお、iPhoneでアプリやWebページを好きな画像から起動したい場合は、**ショートカット**アプリで独自アイコンを作る方法もあります。ただし、元のアプリのアイコンそのものを変更する機能ではありません。

## 追加したのに違うページが開くのはなぜ？

記事や商品ページを追加したつもりでも、起動するとサイトのトップページが開く場合があります。

Webアプリでは、Web App Manifestの`start_url`が起動先として使われることがあります。たとえばサイト側が`"start_url": "/"`を指定していれば、個別ページから追加してもトップページを起点に開く設計になり得ます。

つまり、**今見ているページを追加したら必ずそのページから起動する、とは限りません。**

## 「ホーム画面に追加」が見つからないとき

まずは複雑な設定を変えず、次の順番で確認してください。

1. iPhoneならSafari、AndroidならChromeで**Webページそのもの**を開いているか確認する。
2. iPhoneでは、画像を長押ししたときの共有画面ではなく、**Safariのページ共有メニュー**を開く。
3. iPhoneでは共有メニューの下部にある **「アクションを編集」** も確認する。
4. Androidでは「ホーム画面に追加」だけでなく、 **「インストール」** など別の表記も探す。
5. 一時的な表示の問題なら、ページを再読み込みしてから試す。

**「追加の項目がない」問題と、「追加後のアイコンや起動先がおかしい」問題は別です。** 後者ならサイト側のアイコン設定やWeb App Manifestを確認する必要があります。

詳しい切り分けは[「ホーム画面に追加」が出ない原因と対処法](https://tips.ojapp.app/home-add-cannot/)でも紹介しています。

## 自分の画像を使ってホーム画面に置きたい場合

標準の「ホーム画面に追加」は、すぐにWebページへの入口を作るのに向いています。一方で、**自分のロゴや写真をアイコンにしたい**場合は別の方法が必要です。

iPhoneのショートカットでURLを開くアイコンを作る方法のほか、URLに専用アイコンを設定した入口を作るOJappのようなツールも選択肢になります。ただし、対応する動作や追加手順はツールや端末によって異なります。

[ショートカット・標準のホーム画面追加・OJappの比較](https://tips.ojapp.app/home-custom-compare/)も参考にしてください。

## まとめ

**iPhoneはSafariの共有メニュー、AndroidはChromeのメニューから**Webページをホーム画面に追加できます。

普段よく使うページをすぐ開きたいだけなら、まずは標準機能で十分です。アイコンがサイト共通のロゴになることや、追加したページと起動先が違うことは、サイト側の設定が関係する場合があります。追加できないときは、ブラウザとメニューを確認するところから始めましょう。
