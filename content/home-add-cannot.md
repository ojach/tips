iPhoneでWebサイトをホーム画面に追加したいのに、 **「ホーム画面に追加」が出てこない。**

共有ボタンは見つかったのに項目がない。追加できてもアイコンがおかしい。追加したページではなく、なぜかトップページが開いてしまう。

こうした問題は、すべて同じ原因で起きているわけではありません。

特に「ホーム画面に追加」が見つからない場合、PWAやWebサイトの不具合を疑う前に、**今どの画面から共有メニューを開いているのか**を確認してみてください。

この記事では、iPhoneで「ホーム画面に追加」が出ない原因を、ユーザー側ですぐ確認できるものから、Webサイト・PWA側の設定まで順番に切り分けていきます。

## まず確認：iPhoneの「ホーム画面に追加」はどこにある？

iPhoneでは、Safariで追加したいWebページを開き、そのページの共有メニューからホーム画面へ追加します。

1. 追加したいWebページをSafariで開く
2. Safariの共有ボタンをタップする
3. 共有メニューを下へスクロールする
4. 「ホーム画面に追加」をタップする
5. 必要に応じて「Webアプリとして開く」を選択する
6. 「追加」をタップする

iOSのバージョンやSafariのレイアウトによってボタンの位置や見え方が多少異なりますが、基本的には**Webページを開く → 共有 → ホーム画面に追加**という流れです。

## 「ホーム画面に追加」が出ないときに最初に確認すること

ここからが本題です。

共有メニューを開いたのに「ホーム画面に追加」が見つからない場合、まず次の原因を確認してみてください。

### 原因1：画像の共有シートを開いている

これは意外と気付きにくいポイントです。

Webページに表示されている画像を長押ししたり、画像を単体で開いて共有したりすると、iPhoneには**画像を共有するための共有シート**が表示されます。

しかし、そこで共有している対象はWebページではなく画像です。

そのため、Webページをホーム画面へ追加するための「ホーム画面に追加」を探しても見つかりません。

**共有ボタンを押したのに「ホーム画面に追加」がない場合は、いったん共有画面を閉じてください。**

そしてSafariで追加したいWebページそのものを表示し、その状態からSafariの共有メニューを開き直します。

「共有メニューは開けている」というところまで合っていても、**何を共有しているのか**が違うだけで表示される項目は変わります。

### 原因2：Safariの「アクションを編集」に隠れている

SafariでWebページの共有メニューを開いているのに、「ホーム画面に追加」が見つからない場合もあります。

その場合は、共有メニューを一番下までスクロールして **「アクションを編集」** を開いてみてください。

「ホーム画面に追加」が編集可能なアクションに表示されていれば、ここから共有メニューに戻せます。見当たらない場合は、ほかの原因も確認してください。

つまり、Safariで表示されないからといって、すぐにWebサイトやPWA側の問題とは限りません。

### 原因3：Instagram・X・LINEなどのアプリ内ブラウザで開いている

Instagram、X、LINE、TikTokなどでリンクをタップすると、Safariへ移動せず、そのアプリの中でWebページが開くことがあります。

これは一般に**アプリ内ブラウザ**と呼ばれるものです。

見た目は普通のWebページでもSafariそのものではないため、Safariと同じ共有操作ができなかったり、「ホーム画面に追加」が見つからなかったりすることがあります。

#### 対処法：SafariでWebページを開き直す

アプリ内ブラウザのメニューから「Safariで開く」「ブラウザで開く」などを選択してください。

見つからない場合は、ページのURLをコピーしてSafariへ貼り付けても構いません。

SafariでWebページそのものを開いたら、もう一度共有メニューを確認します。

## Safariなのに「ホーム画面に追加」がない場合

ここまでを一度整理します。

1. 画像ではなくWebページを開いているか
2. Safariで開いているか
3. SafariのWebページから共有メニューを開いているか
4. 「アクションを編集」に隠れていないか

「ホーム画面に追加が出ない」という場合は、まずこの4つを確認するのがおすすめです。

特に最初からManifestやService Workerを疑う必要はありません。ユーザー側で起きている問題なら、ここまでで解決できる可能性があります。

## 「ホーム画面に追加」は出るけど、押しても追加できない場合

「ホーム画面に追加」という項目自体は表示されるものの、その後うまく追加できない場合は少し話が変わります。

まず、すでに同じWebサイトやWebアプリをホーム画面へ追加していないか確認してみてください。

以前追加したアイコンが残っている場合は、まずそのアイコンから正常に開けるか確認しましょう。追加し直して検証する必要がある場合だけ、既存のアイコンを削除してからSafariで再度追加します。

また、一時的なブラウザ側の状態が影響している可能性もあるため、ページの再読み込みやSafariの再起動、必要であればiPhone自体の再起動も試してみてください。

## 追加できたのにアイコンがおかしい場合

ホーム画面への追加自体は成功したものの、アイコンがサイト側の想定と違うこともあります。

たとえば、

- 古いアイコンが表示される
- サイトとは関係ない画像になる
- 想定していたPWAアイコンにならない
- アイコンを変更したのにホーム画面では変わらない

といったケースです。

これは「ホーム画面に追加できない」問題ではなく、サイト側のアイコン設定やiPhone側に残っているアイコン情報が関係している可能性があります。

### サイト制作者はapple-touch-iconを確認する

iPhoneのホーム画面アイコンでは、HTMLに設定された`apple-touch-icon`が影響します。

```html
<link rel="apple-touch-icon" href="/icon.png">
```

自分でもPWA LABやOJappの開発で何度もiPhoneへWebページを追加して検証していますが、iPhoneのアイコン周りはAndroidと同じ感覚で扱わない方がいいと感じています。

Web App Manifestの`icons`だけを確認するのではなく、HTML側の`apple-touch-icon`も確認するのがおすすめです。

また、一度ホーム画面へ追加したアイコンは、Webサイト側の画像を変更してもすぐに変わるとは限りません。

アイコンを変更した直後に確認する場合は、古いホーム画面アイコンを削除してから追加し直した方が切り分けやすくなります。

## 追加したページではなくトップページが開く場合

もう一つよくあるのが、**記事や商品ページをホーム画面に追加したのに、アイコンを押すとサイトのトップページが開く**というケースです。

これはユーザーの追加方法ではなく、サイト側のPWA設計が関係している可能性があります。

### Manifestのstart_urlが「/」になっている

Web App Manifestには、ホーム画面からWebアプリを起動するときの入口を指定する`start_url`があります。

たとえば次のようになっている場合です。

```json
{
  "start_url": "/"
}
```

このPWAがサイト全体を1つのアプリとして扱う設計なら、ホーム画面からの起動先はトップページになります。

`start_url:"/"`自体が間違っているわけではありません。

サイト全体を1つのアプリとして使わせたいなら、普通に成立する設計です。

ただ、自分がPWAを実機で検証する中では、ここをかなり重要視しています。

ユーザーが記事、商品、プロフィール、Webツールなど**特定のURLを見ている状態で「ホーム画面に追加」したのに、次にアイコンを押したらトップページへ戻される**のは、本当にそのサイトに合った体験なのか。

その疑問から、ページ単位で入口を作る1P1A（One Page. One App.）なども検証するようになりました。

つまり、「ホーム画面に追加したページと違うページが開く」場合は、ユーザーが間違ったページを追加したとは限りません。サイト制作者が指定している`start_url`も確認する必要があります。

## PWAの状態が追加導線に関係したように見えるケースも検証した

さらにPWA LABで検証している中では、単純なSafariの操作とは別に、**PWAとしての状態がホーム画面への追加導線に影響しているように見えるケース**も確認しました。

特にサイト全体を1つのアプリとして扱う1S1Aで検証したとき、「ホーム画面に追加」が見つからない原因を追っていくと、PWA側の状態まで関係していたケースがあります。

これは今回紹介した「画像の共有シートを開いていた」「アクションを編集に隠れていた」といった基本的な原因とは別です。

Safariで正しくWebページを開いているのにどうしても追加できない場合は、こちらの実機検証も参考にしてください。

[「ホーム画面に追加」が消えた原因はPWAだった？1S1Aで起きる意外な問題](https://tips.ojapp.app/pwa-home-screen-add-missing-1s1a/)

## サイト制作者向け：「追加できない」と言われたらどこを見る？

自分のWebサイトでユーザーから「ホーム画面に追加できない」と言われた場合も、いきなりPWAのコードを変更するのではなく、まずユーザーがどの状態で操作しているのかを確認する方が早いです。

1. Safariで開いているか
2. Webページの共有メニューを開いているか
3. 「ホーム画面に追加」がアクションから外れていないか
4. 追加自体が失敗しているのか、追加後のアイコンがおかしいのか
5. 追加後に違うURLが開いているだけなのか

ここを分けるだけでも、かなり原因を絞れます。

追加後の問題なら、`apple-touch-icon`、Web App Manifest、`start_url`などサイト側の設定を確認します。

なお、PWAについて調べると「Service Workerがないからインストールできない」という古い説明を見かけることがありますが、現在は**Service WorkerそのものがPWAをインストールするための必須条件ではありません。**

Service Workerはオフライン対応やキャッシュ、バックグラウンド処理などでは重要ですが、「ホーム画面に追加がない＝Service Workerが原因」と決めつけない方が切り分けやすいです。

## iPhoneでホーム画面に追加できないときの結論

iPhoneで「ホーム画面に追加」が出ないときは、難しいPWAの設定を調べる前に、まず**SafariでWebページそのものを共有しているか**を確認してみてください。

画像の共有シートには、Webページをホーム画面へ追加するための項目は出ません。

SafariでWebページを開いているなら、共有メニューの「アクションを編集」も確認します。

InstagramやX、LINEなどから開いている場合は、一度Safariで開き直します。

ここまでやって「ホーム画面に追加」は表示されたものの、アイコンがおかしい、違うページが開く、といった問題が残るなら、そこから先はサイト側のPWA設定を疑います。

**「ホーム画面に追加できない」のか、「追加後の挙動がおかしい」のか。**

この2つを分けて考えるだけでも、原因はかなり探しやすくなります。
