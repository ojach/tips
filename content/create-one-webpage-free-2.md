# 無料でWebページ1枚を作る方法｜初心者でも10分でできる超シンプル手順

「Webページを作ってみたいけど、何から始めればいいかわからない」そんな人は、まずHTMLファイルを1枚作ってみるのがおすすめです。

特別な開発ソフトも、有料サービスへの登録も必要ありません。**パソコンにあるテキスト編集アプリとブラウザだけ**で、自分のWebページを表示できます。

この記事では、コードをコピーして保存し、ブラウザで開くところまでを説明します。慣れていれば10分ほどで試せる内容です。

> この記事で作るのは、まず自分のパソコンで開けるWebページです。インターネット上に公開する作業は含みません。

## 用意するもの

- WindowsまたはMacのパソコン
- テキスト編集アプリ（Windowsならメモ帳、Macならテキストエディット）
- ブラウザ（Chrome、Safari、Edgeなど）

VS Codeなどの開発ツールを新しくインストールする必要はありません。

## 1. `mypage` フォルダを作る

デスクトップなど、わかりやすい場所に `mypage` という名前のフォルダを作ります。これから作るWebページのファイルを入れる場所です。

## 2. `index.html` を作る

`index.html` は、Webページの中身を書くファイル名です。末尾の `.html` が重要です。

**Windowsの場合**は、メモ帳を開いて次のステップのコードを貼り付けたあと、「名前を付けて保存」でファイル名を `index.html` にします。「ファイルの種類」は「すべてのファイル」を選び、文字コードはUTF-8にして `mypage` に保存すると確実です。

すでにテキストファイルを作って名前を変える場合は、エクスプローラーで「ファイル名拡張子」を表示しておきましょう。`index.html.txt` のままだとHTMLファイルとして扱われません。

**Macの場合**は、テキストエディットで「フォーマット」→「標準テキストにする」を選んでからコードを貼り付け、`index.html` として `mypage` に保存します。`.txt` を付けるか確認された場合は、`.html` を使う方を選んでください。

## 3. HTMLコードを貼り付けて保存する

次のコードをそのままコピーして、`index.html` に貼り付けます。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>はじめてのWebページ</title>
  <style>
    body {
      font-family: sans-serif;
      max-width: 640px;
      margin: 60px auto;
      padding: 0 20px;
      line-height: 1.8;
    }
    h1 { color: #2b7bff; }
  </style>
</head>
<body>
  <h1>はじめてのWebページ</h1>
  <p>これは自分で作った、最初のWebページです。</p>
</body>
</html>
```

貼り付けたら保存します。Windowsは `Ctrl + S`、Macは `Command + S` です。

ここで使っているHTMLは文章の構造、CSS（`<style>` の中身）は文字色や余白などの見た目を指定しています。今はすべて理解しなくても大丈夫です。

## 4. ブラウザで開いて完成を確認する

`mypage` フォルダに保存した `index.html` をダブルクリックします。ブラウザに「はじめてのWebページ」という見出しと文章が表示されたら成功です。

もしメモ帳が開いたり、コードがそのまま表示されたりする場合は、ファイル名が `index.html.txt` になっていないか確認してください。ブラウザが自動で開かない場合は、ファイルを右クリックして「プログラムから開く」からブラウザを選べます。

## 5. 文字や色を変えてみる

表示できたら、HTMLの次の部分を書き換えてみましょう。

```html
<h1>私のプロフィール</h1>
<p>ここに自己紹介を書きます。</p>
```

見出しの色を変えたいなら、CSSの `color: #2b7bff;` を別の色コードに変更します。

保存したあとブラウザを再読み込みすると、変更が反映されます。

## 作ったページは他の人にも見える？

今の段階では、`index.html` は自分のパソコンに保存されているだけです。ブラウザで表示できても、URLを友達に送って見てもらえる状態ではありません。

誰でもアクセスできるようにするには、別途Webホスティングなどへファイルを公開する必要があります。 **「作る」と「公開する」は別の作業**だと覚えておけばOKです。

## まとめ

Webページを1枚作るだけなら、必要なのはテキスト編集アプリとブラウザだけ。フォルダを作り、`index.html` にコードを保存して開けば、最初のWebページは完成します。

最初から複雑なツールを覚える必要はありません。まずは文章や色を少し変えて、保存すると表示が変わる感覚をつかんでみてください。
