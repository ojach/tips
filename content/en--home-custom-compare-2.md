# Shortcut vs Web App vs OJapp — A Complete Comparison

When adding a website to your iPhone or Android home screen, there are actually three major methods:

- ① Shortcut Method (iPhone’s automation-based icon customization)
- ② Standard Web App “Add to Home Screen”
- ③ OJapp Method (custom icon + custom name + sharable setup)

 	
 	
 	

This article organizes what each method can and cannot do, so you can choose the best option for your purpose.



## ① What Is the Shortcut Method?

Using the iPhone’s built-in “Shortcuts” app, you can create a pseudo-app with any icon and any name you like.

### Pros

- Full freedom to choose the icon
- You can rename it to anything
- Great for people who want to unify their home screen theme

 	
 	
 	

### Cons

- Setup is complicated, especially for beginners
- Cannot be shared — the other person must recreate it manually
- A Shortcut screen flashes briefly on launch
- You must recreate everything when changing devices

 	
 	
 	
 	

**→ Good for personal use, but too much hassle to recommend to others.**



## ② Standard Web App “Add to Home Screen”

This is the simplest way, available on both iPhone and Android through Safari or Chrome.

### Pros

- Extremely easy — only a few seconds
- Fast launch speed (no Shortcut delay)
- Anyone can do it without explanation

 	
 	
 	

### Cons

- The icon is fixed to the website’s own setting
- Examples: note → “n”, BOOTH → camel icon, BASE → triangle logo
- Low freedom because it depends entirely on the website

 	
 	
 	

**→ Convenient, but unsuitable if you want users to place “your own icon.”**



## ③ What Is the OJapp Method?

OJapp generates a small web page where the icon, app name, and URL are all freely customizable.
Users can then add it to their home screen just like a Web App.

### Pros

- Use any icon you like
- Shareable via a single URL — anyone can recreate the same setup instantly
- No Shortcut required
- Works on both iPhone and Android
- Fast launch speed (no Shortcut delay)

 	
 	
 	
 	
 	

### Cons

- You need to open OJapp once to generate the page
- You need to prepare an icon image

 	
 	

**→ The best option when you want others to place your shop, portfolio, or content on their home screen.**
