# iPhone・Androidのホーム画面アイコンの作り方と作成ツール比較

スマホのホーム画面に並ぶアイコンを、自分の好きな写真やロゴに変えたい。そんなとき、最初に迷うのは「どのアプリで画像を作ればいいのか」ではないでしょうか。

Canvaでデザインする方法もあれば、スマホの写真編集だけで済ませる方法もあります。ただ、ここで一つ知っておきたいことがあります。**アイコン画像を作ることと、その画像をホーム画面に置くことは別の作業**です。

この記事では、画像の作り方と設定方法を分けて、iPhone・Androidで使いやすい選択肢を整理します。

## まずは正方形の画像を用意する

ホーム画面アイコンの素材は、**512×512px以上の正方形**で用意すると扱いやすいです。細部まで作り込みたいなら1024×1024pxで制作しても構いません。ただし、1024pxがすべての端末で必須というわけではありません。

形式はPNGが無難です。写真を使うならJPEGでも編集できますが、ロゴや文字をくっきり見せたい場合はPNGが向いています。背景透過は使う仕組みによって表示結果が異なるため、意図しない背景色を避けたいなら背景を付けて書き出す方が確実です。

アイコンはスマホ上では小さく表示されます。細い文字や複雑な装飾を詰め込むより、**ひと目でわかる形と色**を優先しましょう。角丸の加工はOS側で行われる場合が多いので、素材の段階で無理に角を丸める必要はありません。端に重要な文字やロゴを置かず、少し余白を取ると切れにくくなります。

## 画像を作るなら、どのツールがいい？

### Canva：デザインを揃えたい人向け

[Canva](https://www.canva.com/)は、色や文字、図形を組み合わせてアイコンを作るのに向いています。複数のアイコンを同じ配色で揃えたい場合にも便利です。

作り方はシンプルです。

1. カスタムサイズで1024×1024pxのデザインを作る
2. 背景色を決め、写真や図形、ロゴを配置する
3. 小さく表示しても見分けられるか確認する
4. PNGで書き出す

背景を透過したい場合は、利用中のプランで透過PNGの書き出しに対応しているか確認してください。**アイコン画像のデザインには強い一方、Canvaで書き出しただけではホーム画面のアイコンは変わりません。**

### 写真アプリ・画像編集アプリ：写真をそのまま使いたい人向け

ペットの写真やお気に入りの画像をアイコンにするだけなら、大がかりなデザインツールは不要です。スマホの写真アプリで正方形に切り抜くだけでも、素材として十分使えます。

写真の場合は、主役が中央に来るようにトリミングするのがコツです。背景が細かすぎると、ホーム画面では何の画像かわからなくなりがちです。明るさやコントラストを少し調整するだけでも見やすくなります。

ただし、複数のアイコンを同じ雰囲気で揃えたり、文字や図形を正確に配置したりする用途には、Canvaなどのデザインツールの方が向いています。

### OJapp：作った画像をWebページの入口に使いたい人向け

[OJapp](https://ojapp.app/)は、画像を描くための編集アプリではなく、**好きな画像と名前を設定して、特定のURLをホーム画面から開く入口を作るツール**です。

たとえば、自分のブログやショップ、プロフィールページをオリジナルのアイコンで置きたい場合に使えます。画像そのものはCanvaや写真アプリで用意し、ホーム画面での利用をOJappで設定する、という役割分担です。

一方で、スマホにインストール済みのアプリそのもののアイコンを自由に書き換えるツールではありません。また、作成した入口の表示や起動方法はOS・ブラウザの仕様にも左右されます。

## 用途別に選ぶなら

| やりたいこと | 向いている方法 |
| --- | --- |
| アイコンを一からデザインしたい | Canva |
| 写真をアイコン素材にしたい | 写真アプリ・画像編集アプリ |
| iPhoneでアプリやURLを好きな画像から開きたい | ショートカット |
| ブログやショップのURLをオリジナルアイコンで置きたい | OJappなどのホーム画面追加ツール |
| 自分のWebサイトの公式アイコンを設定したい | Web App Manifestなどのサイト側設定 |

ここで重要なのは、**画像制作ツールとホーム画面への設定方法を混同しないこと**です。

## iPhoneで好きな画像のアイコンをホーム画面に置く

iPhoneで、自分だけのアイコンからアプリやURLを開きたいなら、標準の「ショートカット」アプリが代表的な方法です。

1. ショートカットアプリで新しいショートカットを作る
2. 「アプリを開く」またはURLを開くアクションを設定する
3. 共有メニューなどから「ホーム画面に追加」を選ぶ
4. 名前とアイコン画像を指定して追加する

操作名や画面構成はiOSのバージョンによって変わることがあります。

これは**元のアプリのアイコンを変更するのではなく、指定した動作を実行する新しいホーム画面アイコンを作る方法**です。元のアプリアイコンはそのまま残ります。

また、WebサイトをSafariから「ホーム画面に追加」する方法もあります。ただし、その場合に表示されるアイコンはサイト側の設定やSafariの扱いに影響されるため、好きな画像を必ず選べるとは限りません。

## Androidで好きな画像のアイコンをホーム画面に置く

Androidでは、ChromeなどでWebサイトを開き、「ホーム画面に追加」や「インストール」を選ぶ方法があります。サイトの対応状況によって、単なるショートカットになる場合と、Webアプリとして追加される場合があります。

表示されるアイコンは、Webサイトの設定やブラウザ、ホームアプリによって変わります。**Android標準の操作だけで、どんなURLやアプリにも自由な画像を指定できるとは限りません。**

既存アプリの見た目を変えたい場合は、使っているホームアプリのアイコン変更機能やアイコンパックへの対応を確認します。機種やランチャーによって操作が違うため、iPhoneのショートカットと同じ手順にはなりません。

自分のWebページのアイコンを管理する側なら、Web App Manifestの`icons`を設定する方法もあります。Android向けには、通常のアイコンに加えて`maskable`用画像を用意すると、端末のアイコン形状に合わせやすくなります。

## 作ったのにきれいに表示されないとき

画像を設定したのに、思ったように表示されないこともあります。

- **ぼやける：** 元画像が小さすぎないか、拡大して書き出していないか確認する
- **端が切れる：** ロゴや文字を中央に寄せ、周囲に余白を作る
- **背景が変わる：** 透過画像の扱いを確認し、必要なら背景色を付ける
- **古い画像が出る：** ブラウザやOS側に以前のアイコンが残っている可能性がある
- **端末ごとに違う：** iOS・Androidやホームアプリでアイコンの処理が異なる

特にWebサイトのホーム画面アイコンは、画像ファイルを差し替えてもすぐ更新されるとは限りません。設定を変えた後は、実際の端末で追加し直して確認するのが確実です。

## まとめ：画像を作る道具と、置く方法を分けて考える

ホーム画面アイコンを作るなら、まず正方形の画像を用意します。デザインを揃えたいならCanva、写真を使うだけならスマホの編集機能で十分です。

その画像をどう使うかは別の話です。iPhoneで自分用の起動アイコンを作るならショートカット、Webページを専用のアイコンで置きたいならホーム画面追加用ツールやサイト側のPWA設定が候補になります。Androidではホームアプリやブラウザの違いも確認が必要です。

**どこで画像を作るかより、何を開くアイコンにしたいのか。** そこを先に決めると、遠回りせずに済みます。
