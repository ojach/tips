Webページを作ろうと思って調べると、必ず出てくるのが **HTML・CSS・JavaScript** という3つの名前です。

「全部プログラミング言語なの？」「どれから覚えたらいいの？」と戸惑うかもしれません。でも、最初から難しい言葉を覚える必要はありません。

今回は**家づくり**に例えて、3つの役割を説明します。最後には、実際に3つを使った小さなWebページも作ってみましょう。

## まず答え：HTMLは中身、CSSは見た目、JavaScriptは動き

| 名前 | 家づくりに例えると | Webページでの役割 |
| --- | --- | --- |
| HTML | 柱・壁・部屋 | 文章や画像、ボタンなどを置く |
| CSS | 壁紙・色・家具の配置 | 色、大きさ、並び方を整える |
| JavaScript | スイッチ・電気・自動ドア | 押したときの反応や表示の切り替えを作る |

例えば「赤いボタンを押したら、画面に『こんにちは！』と表示する」ページなら、ボタンを置くのがHTML、赤くするのがCSS、押したときに文字を変えるのがJavaScriptです。

このイメージがつかめれば、最初の一歩は十分です。

## HTMLは家の「骨組み」と「中身」

家を建てるときは、まず部屋やドアの場所を決めますよね。Webページでその役割を持つのがHTMLです。

例えば、見出し、説明文、画像、リンク、ボタンなどを「ここに置く」と決めます。

```html
<h1>ぼくのWebページ</h1>
<p>はじめて作ったページです。</p>
<button>押してみて</button>
```

`<h1>` は大きな見出し、`<p>` は文章、`<button>` はボタンを表します。山かっこで囲まれた部分を**タグ**と呼びます。

HTMLは文章に「これは見出し」「これはボタン」という意味をつける仕組みでもあります。見た目だけでなく、ブラウザや読み上げ機能にページの構造を伝える大事な仕事があります。

ただし、**HTMLだけでもWebページは作れます。** 何も飾っていない家のように見えるかもしれませんが、文章やリンクを表示することはできます。

## CSSは家の「色」と「インテリア」

骨組みができたら、壁を何色にするか、家具をどう並べるかを考えます。Webページで見た目を担当するのがCSSです。

```css
h1 {
  color: royalblue;
}

button {
  background: orange;
  padding: 12px 20px;
  border: none;
  border-radius: 8px;
}
```

これを使うと、見出しは青色に、ボタンはオレンジ色で角が丸い見た目になります。

CSSが得意なのは色だけではありません。文字の大きさ、余白、画像の幅、スマホとパソコンでの並び方まで調整できます。

例えば、パソコンでは横に並ぶカードを、スマホでは縦に並べる。こうした**画面サイズに合わせたデザイン**もCSSの仕事です。

HTMLが「何を置くか」を決めるなら、CSSは「どう見せるか」を決める。ここを分けて考えると理解しやすくなります。

## JavaScriptは家の「スイッチ」と「機械」

家には照明のスイッチや自動ドアがあります。押したり近づいたりすると何かが起こりますよね。

Webページで、こうした**操作に反応する仕組み**を作れるのがJavaScriptです。

```javascript
const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("こんにちは！");
});
```

このコードは、ボタンがクリックされたときに「こんにちは！」というメッセージを表示します。

JavaScriptでできるのはボタンの反応だけではありません。メニューの開閉、入力内容のチェック、時計の表示、データの読み込みなど、Webページのさまざまな動きを作れます。

ただし、JavaScriptがないとWebページが成立しないわけではありません。読むだけのページならHTMLとCSSだけでも十分です。**必要なときに動きを足す**のがJavaScriptだと考えてください。

## 3つをまとめて使ってみよう

言葉だけではわかりにくいので、3つが協力する小さなページを作ります。

パソコンのメモ帳などに次のコードを貼り付け、`index.html` という名前で保存してください。ファイルをブラウザで開けば動きます。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>はじめてのWebページ</title>
  <style>
    body {
      font-family: sans-serif;
      text-align: center;
      padding: 40px 16px;
    }
    button {
      background: orange;
      border: 0;
      border-radius: 8px;
      padding: 12px 20px;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <h1>ぼくのWebページ</h1>
  <p id="message">ボタンを押してみよう！</p>
  <button id="hello">押してみて</button>
  <script>
    document.querySelector("#hello").addEventListener("click", () => {
      document.querySelector("#message").textContent = "こんにちは！";
    });
  </script>
</body>
</html>
```

ページを開いたら、オレンジ色のボタンを押してみてください。上の文章が「こんにちは！」に変わるはずです。

ここで役割を分解すると、`<h1>` や `<button>` を書いた部分がHTML、`<style>` の中がCSS、`<script>` の中がJavaScriptです。

たった1つのファイルですが、**中身・見た目・動き**が全部入っています。最初は3つを別々のファイルにする必要もありません。

## どれから勉強すればいい？

おすすめの順番は **HTML → CSS → JavaScript** です。

最初にHTMLで見出しや文章を置けるようになる。次にCSSで色や余白を変える。そして最後にJavaScriptでボタンを動かしてみる。この順番なら、それぞれの役割が目で見てわかります。

最初から難しいアプリを作ろうとしなくても大丈夫です。見出しの文字を変える、ボタンの色を変える、押したときのメッセージを変える。それだけでも、立派なWeb制作の練習になります。

## よくある疑問

### HTMLとCSSだけでWebページは作れる？

作れます。文章や画像を見せるページなら、JavaScriptなしでも十分に役立ちます。むしろ動きが不要なら、無理にJavaScriptを入れる必要はありません。

### HTMLはプログラミング言語？

一般には**マークアップ言語**と呼びます。文章の意味や構造をタグで示すための言語です。一方、JavaScriptは処理の手順や条件を書けるプログラミング言語です。

### CSSだけでボタンを動かせる？

押したときに色を変えたり、アニメーションをつけたりすることはできます。ただし、入力内容を使って計算したり、別の文章に書き換えたりするような処理にはJavaScriptが向いています。

## まとめ

家づくりに例えると、**HTMLは骨組みと中身、CSSはデザイン、JavaScriptはスイッチや機械**です。

3つを一度に完璧に覚える必要はありません。まずはHTMLで何かを表示して、CSSで見た目を変えて、JavaScriptで反応をつけてみる。そうすると、Webページがどうやってできているのかが自然に見えてきます。
